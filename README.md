# spell-gram

A Python-based tool to help with spelling and grammar checking offline.  

## 🧠 Features

- Spell checking of input text  
- Grammar correction suggestions  
- Desktop application
- Easy integration into other workflows or scripts  

## 📦 Getting Started

### Prerequisites  
- Python 3.x  

### Installation  
```bash
git clone https://github.com/mzziin/spell-gram.git
cd spell-gram
pip install -r requirements.txt
